# PE Lab Catalog

| Lab | Title | Learning objective |
|---|---|---|
| [PE-M1-L1](PE-M1-L1-Authorized-Access-Review.md) | Authorized Access Review | Identify people who retain physical access without current authorization. |

| [PE-M2-L2](PE-M2-L2-Temporary-Badge-Workflow.md) | Temporary Badge Workflow | Execute the full temporary badge lifecycle. |
| [PE-M3-L1](PE-M3-L1-Access-Log-Review.md) | Access Log Review | Reconcile multiple physical-access records and identify discrepancies. |
| [PE-M3-L2](PE-M3-L2-Lost-Badge-Response.md) | Lost Badge Response | Contain a lost badge, issue a replacement, and document post-loss use. |

All labs are evidence-driven and run from the shared DC artifact directory. No lab modifies another family's artifacts.
